Global Enterprise Monitoring Rules

Configure desktop client parameters, idle thresholds, sync frequencies & screenshot encryption policies.

⚙️ General Monitoring Policy

Monitoring Enabled Globally enables background client activity tracking across company devices.
Idle Timeout (Minutes) Inactivity threshold before marking employee state as Idle.
Idle Counts As Work If enabled, idle hours are added into gross paid timesheet hours.
Activity Tracking Enabled Tracks active window titles, desktop applications and web domain URLs.
Activity Sample Interval (Seconds) Frequency of sampling active window and domain state on client agent.
Sync Interval (Minutes) Frequency of client batch telemetry upload to Obelisk Cloud server.

📷 Screenshot Capture Policy

Screenshots Enabled Captures periodic automated screen snapshots during active work timers.
Screenshots Per Hour Target random sample captures performed per hour per employee.
Screenshot Quality Image resolution compression applied before server upload.
Blur Screenshots Automatically applies Gaussian blur to protect sensitive employee text and fields.
Retention Days Automated retention purge period for stored screenshot assets.
